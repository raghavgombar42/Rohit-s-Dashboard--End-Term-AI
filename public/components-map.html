The Cut

Three things the engine never does

  • Never emails a founder or sends on its own. Every draft is addressed to the safe-mode test inbox; sending needs Rohit's click in operator mode.
  • Never contacts a startup twice. A database unique index allows one outreach per startup, ever. Rejected and Gmail-handled drafts count as history.
  • Never invents. Funding facts, founders and contacts must come from fetched sources; quotes are checked by code; email addresses are never guessed.
AI proposes, code decides

Where judgement sits

Gemini reads, extracts, researches, scores and writes. Every decision that must be predictable is code or a database constraint: dedup, dates and recency, stage and geography gates, quote verification, weights and threshold, state transitions, one-outreach-per-startup and send-once.

When Rohit edits the thesis, rounds not yet drafted are re-scored on the next run. Threshold or weight changes are re-applied by code to the same verified scores (no AI call); wording or sector changes ask Gemini again.
